# Analisi del primo programma
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, world");
    }
}
```

## Classe
La prima riga `public class Hello` definisce una classe di nome Hello. Le classi sono contenitori o fabbriche di oggetti e sono fondamentali in Java, in quanto linguaggio orientato agli oggetti. Al momento, consideriamo gli oggetti come elementi da manipolare. Le classi correlate possono essere inserite in un package.

Ogni file sorgente può contenere solamente una classe pubblica, e il suo nome deve coincidere con quello del file. Possono essere presenti anche altre classi, ma private, nello stesso file.

NOTA: `class`, `public`, `static`, `void` ecc sono parole chiave/riservate. Non posso usarle come nome di una classe, metodo, variabile, parametro... Java è anche case sensitive quindi `Class` e `class` sono diversi.

`public` indica che la classe Hello può essere usata da tutte le altre classi. Più avanti vedremo anche `private` e `protected`.

Per il momento useremo le classi solo contenitori, non come fabbriche di oggetti. È però comunque presente quest'altro ruolo.

## Metodo
Un metodo serve a definire una sequenza di istruzioni (*enunciati*) che descrive come svolgere un determinato compito (in altri linguaggi, i metodi sono chiamati anche funzioni o procedure).

Un metodo deve necessariamente essere inserito in una classe.
Un programma Java eseguibile **deve** avere il metodo `main`.

`public static void main(String[] args)`
Anche qui, `public` significa utilizzabile da tutti. `static` invece significa che il metodo non esamina e non modifica gli oggetti della classe `Hello`. `void` invece significa che il metodo non restituisce un valore quando eseguito.

Il corpo di un metodo è racchiuso tra parentesi graffe. Gli enunciati del metodo vengono eseguiti nella sequenza in cui sono scritti. Ogni enunciato termina con il carattere `;`.

## Stampa
`System.out.println("Hello, world");`
Dove va la "stampa" di questo testo? In questo caso la destinazione è lo standard output (stdout in linux). All'interno del programma Java, l'output standard è rappresentato dall'oggetto `out` di `System`, precaricato automaticamente da Java nei programmi.

Quando si usa un oggetto, bisogna specificare cosa si vuole fare con l'oggetto stesso (=che metodo voglio eseguire/che variabile voglio modificare o leggere). In questo caso si esegue il metodo `println`.

Attenzione: il carattere punto può significare sia *usa un oggetto di questa classe* o *usa un metodo di un oggetto*. Il compilatore è in grado di interpretare questa ambiguità, in quanto dipende dal contesto e non da altro.

Se voglio invocare un metodo, devo indicare i parametri se necessari, e se non necessari devo comunque aggiungere le parentesi dopo il nome del metodo (es. `println()`). Se ci sono più parametri, vanno separati tramite virgola. I parametri necessari per i metodi sono indicati nella documentazione (java api ufficiali se in libreria, javadoc scritti dal creatore del metodo se non in libreria).

Una sequenza di caratteri tra virgolette si chiama stringa (oggetto di classe `String`). Quello che è tra virgolette non viene interpretato dal compilatore ed eseguito (ad es., posso scrivere `private String nome = "class"`) senza problemi.

Dentro a `println`, posso usare anche addizioni, sottrazioni, variabili ecc, e anche concatenare stringhe con `+`. Le eventuali operazioni matematiche tra virgolette **non** vengono interpretate, in quanto stringhe.
