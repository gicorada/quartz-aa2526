# Rappresentazione delle informazioni nei calcolatori (parte 1)
Noi utilizziamo la notazione decimale per i numeri e simboli per le lettere. Il computer invece capisce solo 0/1.

Ci sono differenze tra queste notazioni: i valori numerici sono infiniti, i bit che il computer dedica a rappresentare i numeri non sono infiniti: ci sono dei limiti alla rappresentazione di questi valori. I limiti sono valore massimo/minimo e precisione della rappresentazione. Il computer inoltre tratta i caratteri come numeri, ed è necessaria quindi una tabella di conversione (ascii, unicode...).

I numeri che siamo abituati ad utilizzare sono espressi:
- in base decimale (usano dieci cifre, 0..9)
- con notazione posizionale (cifre uguali in posizioni diverse hanno valore diverso) -> Il peso di una cifra è dato dalla base (10 nel decimale) elevato alla potenza della posizione della cifra

Esempio di numero in base decimale: 434 = $4*10^2 + 3*10^1 +  4*10^0$

In generale, con N cifre abbiamo
$$
a_{n-1} a_{n-2} ...a_{0} = \sum_{k=0}^{n-1} a_k b^k
$$
L’eventuale parte frazionaria, a destra del simbolo separatore, si valuta con potenze negative:
$4.34 = 4*100 + 3*10^{-1} + 4*10{-2}$

I computer invece usano numeri binari, con notazione posizionale in base binaria
- usa solo due cifre diverse, 0 e 1
- la conversione da base binaria a decimale è semplice:
	- $(1101)_2$ = $(1*2^3 + 1*2^2 + 0*2^1 + 1*2^0)_{10}$ = $13_{10}$
- la rappresentazione binaria è più facilmente manipolabile dal computer

La conversione di un numero da base decimale a base binaria è, invece, un po' più complessa: la parte intera del numero va elaborata indipendentemente dalla eventuale parte frazionaria

Per convertire la sola parte intera:
- Si divide il numero per 2
- Si elimina l’eventuale resto
- Si continua a dividere per 2 il quoziente ottenuto fino a quando non si ottiene quoziente uguale a 0
- 
Il numero binario si ottiene scrivendo la sequenza dei resti delle divisioni, iniziando dall’ultimo resto ottenuto. Attenzione: non fermarsi quando si ottiene quoziente 1, ma proseguire fino a 0

```
100/2 = 50 resto 0
50/2  = 25 resto 0
25/2  = 12 resto 1
12/2  =  6 resto 0
6/2   =  3 resto 0
3/2   =  1 resto 1
1/2   =  0 resto 1
```

Partendo dal basso quindi ho $1100100_2 = 100_{10}$

Esercizio:
	75/2 37 1
	37/2 18 1
	18/2 9 0
	9/2 4 1
	4/2 2 0
	2/2 1 0
	1/2 0 1

Per convertire la sola parte frazionaria si moltiplica il numero per 2, sottraendo 1 dal prodotto se > 1, continuando a moltiplicare per 2 il risultato

```
0.35 * 2 = 0.7
0.7 * 2  = 1.4
0.4 * 2  = 0.8
0.8 * 2  = 1.6
0.6 * 2  = 1.2
0.2 * 2  = 0.4
```
In questo caso, il numero è anche periodico dato che si ripeterebbe la sequenza se continuassi. Prendo nell'ordine in cui ho calcolato le cifre intere dei risultati (non in ordine inverso come per gli interi). Il numero è quindi $0.01\overline{0110}$.
