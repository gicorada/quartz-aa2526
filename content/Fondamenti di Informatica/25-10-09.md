# Sistemi operativi
Un OS è una collezione di programmi che consente di utilizzare il computer tramite operazioni fondamentali, inizializzando il sistema e assicurando il corretto funzionamento della macchina. Prima di poter eseguire qualsiasi software nella memoria deve essere caricato l'OS.

I sistemi operativi attualmente più utilizzati sono Windows, Linux, MacOS e Android.

I sistemi operativi nascondono all'utente i dettagli tecnici legati all'architettura del computer (ovvero tutta la struttura di CPU, RAM, registri ecc). Garantiscono l'operatività di base di un computer interagendo con l'hardware, facendo da interfaccia con l'utente.

Ogni sistema operativo fornisce ai software delle basi per interagire con il computer, e queste basi possono variare in base all'OS (ad esempio, i software linux saranno progettati per interagire con l'OS in modo diverso che quelli di Windows).

La procedura di avvio di un pc è chiamata bootstrap, ed è memorizzata nella ROM. La CPU legge questa sequenza di istruzioni e le usa per inizializzare la macchina. Cerca poi il sistema operativo, che viene caricato in RAM, che una volta eseguito permette l'utilizzo dei vari software del pc.

I programmi dell'OS si possono classificare in base alla vicinanza con i componenti hardware. Esistono diversi livelli.
1) HAL: Hardware abstraction layer, interagisce direttamente con l'hardware, fornisce astrazione per i driver. Permette al kernel di comunicare con i componenti hardware senza necessità di conoscere i dettagli specifici dell'hardware
2) Driver di dispositivo e gestione I/O: gestiscono la comunicazione con specifici dispositivi hardware, fornendo un'interfaccia standard
   Gestione dei processi: responsabile della gestione di creazione, pianificazione e terminazione dei processi. Gestisce il multitasking e le priorità dei processi
3) Gestione della memoria: gestisce la memoria di sistema, si occupa dell'allocazione e deallocazione, del paging e dello swapping
   Gestione del file system: fornisce le funzionalità per leggere e scrivere file. Si assicura che i file siano accessibili e organizzati
4) Networking: gestisce le interfacce di rete, implementa protocolli come tcp/ip
   Comunicazione IPC (interprocesso): fornisce meccanismi per la comunicazione tra processi, come pipe, semafori, memoria condivisa
5) Interfaccia delle chiamate di sistema: funge da ponte tra utente e kernel. Può interagire direttamente con la base del sistema operativo
6) Interfaccia utente: costituita dai programmi che comunicano con l'utente, è lo strato più alto del sistema, può essere sia CLI che GUI

Ogni sistema operativo ha un linguaggio di controllo. Sono un elenco di comandi che si possono utilizzare, ed ogni comando ha una sintassi e grammatica molto rigida. I comandi sono impartiti dall'utente tramite riga di comando (nei sistemi operativi con GUI questi comandi spesso sono nascosti).

# Linux
Linux nasce da Linus Torvalds, studente finlandese, nel 1991, insoddisfatto dalle alternative.

Punti chiave:
- Licenza GNU: licenza aperta, condivisione, modifica e utilizzo permesso a tutti
- Collaborazione globale: essendo open source chiunque può collaborare, e molti hanno contribuito al progetto
- Utilizzato ovunque

### Autenticazione
Nei sistemi UNIX-like, ogni utente ha un username e una password, memorizzati in `/etc/passwd`. I file possono avere diritti di accesso, tramite organizzazione degli utenti in gruppi logici, che permettono di assegnare permessi di lettura/scrittura/esecuzione a specifici utenti o gruppi di utenti. L'utente `root` ha tutti i permessi.

### Filesystem
Il filesystem di linux è organizzato in directory e file, memorizzati in struttura ad albero. Ogni fs ha una directory speciale, `/`, cartella root, che contiene tutti gli altri oggetti.

Gli oggetti sono identificati da un percorso, che può essere assoluto (dalla radice), come `/home/utente/file.txt`, oppure relativo, come `./utente/file.txt` (che equivale a quello precedente se si è nella directory `home`).
Nella costruzione dei percorsi possiamo usare delle "cartelle virtuali", `.` per indicare la directory attuale, `..` per indicare la directory genitore. Esiste anche `~` per indicare la home directory dell'utente.

Quanti filesystem ci sono? Su windows, ce n'è uno per disco/partizione. Su linux, c'è solo un filesystem, e le altre partizioni vengono montate come cartelle (tipicamente in `/mnt`).

Le cartelle più importanti del filesystem sono:
- `/bin`: contiene eseguibili binari essenziali al sistema per operare. Esempi: `ls`, `cp`, `mv`
- `/boot`: contiene i file necessari per l'avvio del sistema, come kernel e configurazione del bootloader
- `/dev`: contiene tutti i file che rappresentano le periferiche hardware (mouse, tastiera, dischi)
- `/etc`: contiene i file di configurazione dell'OS e dei software installati, come anche configurazioni di rete
- `/lib`: contiene le librerie condivise essenziali per l'uso degli eseguibili in `/bin` (circa quello che sono i file `.dll` in windows)
- `/media`: punto di montaggio dei media removibili, come CD, penne USB
- `/mnt`: punto di montaggio temporaneo per i file system. Spesso gli amministratori di sistema lo usano per montare file system manualmente
- `/opt`: contiene i pacchetti software opzionali (non di sistema). Le applicazioni che sono in questa directory sono spesso indipendenti
- `/proc`: file system virtuale che permette di indagare lo stato dei processi e i parametri del kernel. Viene utilizzato per accedere a informazioni su processi e sistema
- `/root`: directory personale dell'utente root, accessibile solo a lui
- `/sbin`: contiene gli eseguibili di sistema, utilizzati principalmente dagli amministratori
- `/srv`: contiene i dati per i servizi forniti dal sistema, come file di server web o condivisioni FTP
- `/tmp`: directory temporanea utilizzata per memorizzare file temporaneamente. La cancellazione avviene in modo automatico periodicamente
- `/usr`: contiene utilità e applicazioni per gli utenti
- `/var`: contiene file variabili, come log, database, code di spool. I dati dentro a questa cartella possono cambiare spesso la loro dimensione (in particolare i log)

I file di dispositivo identificano una particolare periferica:
- A caratteri: tastiera, stampante, scheda audio
- A blocchi, con accesso casuale e si agisce per blocchi: dischi sata (`/dev/sda`), partizioni, NVME, ecc

### Shell
La shell è un componente fondamentale di Linux e Unix. È un'interfaccia a riga di comando che consente di interagire con il sistema operativo. La shell presenta un prompt che ci indica se il sistema è pronto a ricevere comandi da noi.

Noi possiamo interagire con la shell tramite comandi che permettono la gestione di file, directory, processi e la configurazione del sistema. Possiamo inserire i comandi e poi premere enter per eseguirli.

Esistono due tipi di comandi:
- Builtin: eseguiti dalla shell stessa, senza coinvolgere processi aggiuntivi. Spesso `cd`, `ls`, `rm`, `mkdir`, `mv` e simili sono builtin
- Esterni: vengono eseguiti indipendentemente dal processo della shell. Possono avviare anche interfacce grafiche, come anche TUI o CLI.

Tipicamente un comando richiede parametri: si inseriscono dopo il comando, e variano in base al comando. Ad esempio, cp richiede il file originale e il file di destinazione (`cp ./file.txt ./copia.txt`), ma può ricevere anche più parametri.

I parametri possono essere preceduti da `-` o da `--`, a discrezione del comando, ed in questo caso vengono chiamati opzioni. Queste possono essere concatenate, in modi diversi a discrezione del comando. Ad esempio, molti comandi hanno l'opzione `--help`, che serve a fornire informazioni utili su come usare il comando. Molti comandi considerano l'opzione `-h` equivalente a `--help`.

>(Nota: per me è sempre utile guardare il manuale tramite `man <comando>` oppure usando la forma completa `--help` prima di eseguire un comando che non si conosce).

Esistono altri comandi che permettono di avere più informazioni su un comando:
- `apropos <comando>`: restituisce tutti i comandi che hanno nel nome o nella descrizione la stringa fornita
- `whatis <comando>`: sintesi di quello che fa il comando
- `man`: Questo comando fornisce un'informazione più esaustiva, con molti più dettagli dei comandi precedenti e di `-h`

Alcuni parametri interessanti di `ls`:
- `ls -l`: visualizza i file, con in più permessi di accesso, utente e gruppo proprietario, e data di ultima modifica
- `ls -a`: visualizza anche i file nascosti (ovvero quelli che iniziano con `.`, come `.bashrc`)
- `ls -R`: visualizza ricorsivamente i file all'interno delle directory presenti in quella in cui viene eseguito il comando

E se nella mia cartella voglio vedere cosa inizia con "test"? Posso usare i caratteri speciali come `*`: `ls test*` mostra tutto quello che inizia con "test" nella directory attuale. Altri si possono trovare nella documentazione.

Il comando `cd <path>` permette di cambiare directory, fornendo il nome della directory in cui entrare (path assoluta o relativa). Senza path, torna a `~` ovvero la home directory.

Il comando `pwd` permette di visualizzare la directory attuale, tramite percorso assoluto.

Il comando `mkdir <cartella>` permette di creare una cartella con il nome fornito.

Il comando `rmdir <cartella>` permette di eliminare la cartella con il nome fornito, se presente e **senza file al suo interno**.

Il comando `rm [<parametri>] <path>` invece permette di cancellare file e directory, anche se non vuote. Posso applicarlo alla cartella con l'opzione `-r`, oppure cancellare tutto il contenuto della cartella con il carattere `<path>/*`. L'opzione `-i` invece chiede conferma interattiva per la cancellazione di ogni file. `-f` invece elimina forzatamente tutti i file.

>Nota: l'uso delle opzioni `-rf` unite può essere pericoloso, in quanto non viene richiesta conferma e la cancellazione è ricorsiva. Vanno usate con cautela soprattutto quando si agisce con privilegi alti, in quanto c'è la possibilità di poter cancellare l'intero sistema operativo se si agisce sulla root.

Il comando `mv <source> <dest>` permette di spostare la directory/file indicato come primo parametro nella directory/file indicato come secondo parametro. Possono essere usati con path relativi o assoluti. Può essere usato anche per rinominare il file, "spostando" il primo file in un secondo file con il nome scelto.
