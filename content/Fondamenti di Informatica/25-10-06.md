Linguaggi ad alto livello:
- Compilati
- Interpretati

## Compilati
Compilatore è un programma che riceve in ingresso il codice e ritorna in output il programma nel linguaggio macchina della CPU. Verifica quindi anche che non ci siano errori sintattici (ma non logici, non è possibile verificarli).

Il compilatore fa in modo che:
- I linguaggi sono indipendenti dalla CPU
- Il prodotto della compilazione è dipendente dalla CPU
Per questo, è necessario compilare il programma per ogni tipologia di CPU per la quale si vuole essere in grado di eseguire il programma.

## Interpretati
L'interprete traduce al volo il codice sorgente in eseguibile, senza creare un file eseguibile. Ad ogni esecuzione del programma, l'interprete deve leggere, tradurre ed eseguire il programma. Questo lo rende generalmente più lento dei linguaggi compilati.

---

I primi linguaggi ad alto livello partono dagli anni 50 (FORTRAN, BASIC, COBOL). Questi avevano ancora i salti condizionati/non condizionati, provocando minore leggibilità del codice.

Negli anni 60/70 si passa alla programmazione strutturata: C, Pascal. Ci sono strutture di controllo ed è garantita la componibilità evitando salti nel codice (un punto di ingresso, un punto di uscita).

Negli 80/90 si passa alla OOP, con C++ e Java. Definiscono modelli astratti che descrivono dati e relative operazioni che è possibile eseguire sul modello.

La sintassi dei linguaggi di programmazione, essendo artificiali, è molto rigida per agevolare il compilatore/interprete. Il compilatore rileva errori di sintassi (parentesi di troppo, mancanza di punto e virgola ecc), ma non cerca di capire le intenzioni del programmatore e si limita a segnalare gli errori.

```java
if (rate > 100)) // < - - C'è una parentesi di troppo, compilatore lo segnalerà
	System.out.print("Troppo");
```

NOTA: ricordarsi di compilare/eseguire spesso, non programmare "bendati" sperando che funzioni e non ci siano errori

Esistono molti linguaggi ad alto livello:
```java
//Java
if (rate > 100)	System.out.print("Troppo");
```

```pascal
//Pascal
if rate > 100 then write('Troppo');
```
Questi due snippet fanno la stessa cosa, ma in due linguaggi diversi

# Introduzione a Java
Java nasce nel 1991 ed è sviluppato da Sun Microsystems. È stato progettato per essere semplice e indipendente dalla CPU. Il primo progetto Java fu un browser che permetteva di eseguire applet in locale. È in costante sviluppo dalla sua introduzione.

Java è stato adottato da molte aziende e programmatori perché:
- È più semplice di C++ (suo diretto concorrente)
- Consente di scrivere e compilare una sola volta il codice, per poi poterlo eseguire su tutte le piattaforme/CPU. Usa infatti come motto "compile once, run anywhere"
- Non viene generato direttamente codice macchina dal compilatore, viene invece generato bytecode (codice intermedio) che poi viene interpretato dalla JVM
- La libreria standard è ricca di funzionalità (come anche altri linguaggi di programmazione)

Per effettuare molte operazioni comuni (scrivere sulla shell ecc...) è necessario interagire con il sistema operativo tramite operazioni di basso livello. Java ha già provveduto ad implementare nelle classi standard (in particolare System per l'interazione con l'OS) presenti in libreria, che è già bytecode (non è necessario avere il codice sorgente per usarle).

Java non è orientato alla didattica: non è molto semplice scrivere programmi semplici, in quanto è molto strutturato (è necessario creare una classe anche solo per eseguire uno snippet di codice). Inizialmente daremo alcuni costrutti Java come scontati.

---
In generale, con i linguaggi compilati, ci sono tre fasi:
- Scrittura del codice sorgente
- Compilazione del codice sorgente in codice eseguibile
- Esecuzione del programma

Per scrivere codice sorgente, si usa un editor di testo, salvando il codice in un file. Nel linguaggio Java, il file deve avere estensione `.java`. Esempio: `Hello.java`

Per compilare il codice, si usa il comando `javac` seguito dal nome del file java. Esempio: `javac Hello.java`. Il compilatore genera un file con lo stesso nome ed estensione `.class`. Questo è il bytecode che poi viene passato alla JVM.

La JVM è un programma che ha lo scopo di eseguire altri programmi (emula il funzionamento del processore). Permette di eseguire programmi Java, e gestisce e ottimizza l'uso della memoria da parte di essi.

L'interprete java viene invocato con il comando `java` e il nome del file (senza estensione). Esempio: `java Hello`. Questo carica il programma in RAM e lo avvia, caricando eventualmente altri bytecode delle classi di libreria usate.
